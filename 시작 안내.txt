훈련병장 회귀자는 전역하고 싶어 — 프롤로그와 두 가지 훈련

실행
프로젝트 폴더의 '게임 실행.cmd'를 더블클릭하세요.
이 PC에 설치한 Godot 엔진으로 Windows 게임 창이 열립니다.
프로젝트 수정은 Godot에서 project.godot을 열어 진행합니다.
사격만 바로 해보려면 타이틀의 '사격 바로하기'를 누르세요. 프롤로그나 제식 평가를 먼저 할 필요가 없습니다.

조작
GAME START: 클릭 또는 Enter
이름 입력: Windows 기본 입력창에서 기본값 윤준성을 수정하고 OK를 누릅니다. 최대 12자입니다.
게임 화면에서 완성된 이름을 확인하고 '이야기 시작'을 누릅니다.
대사: 클릭 / Space / Enter
글자가 나오는 중 클릭: 해당 대사 즉시 표시
Esc: 메뉴 / 창 닫기
F11: 전체 화면
장면은 자동 저장됩니다. 타이틀에서 '이어서 보기'로 이어갈 수 있습니다.
새 이야기는 본편 훈련 진행과 탐색 위치를 초기화합니다. 계정의 재도전 해금·코인·보유 물품은 유지됩니다.
이전에 완료한 훈련을 새 이야기에서 다시 통과해도 최초 완료 추가 보상은 중복 지급되지 않습니다.

현재 범위
타이틀 등장 → 이름 입력 → 전역날 아침 → 행정반 → 위병소 작별
→ 경적과 사고 → 암전 → 훈련소 이틀 차 → 회귀 자각 → 침상 정리 퀘스트.
경적 → 당황 → 충돌의 세 장면은 자동으로 이어지며, 나머지 대사는 직접 넘깁니다.
회귀 대사 마지막에서 일러스트 퀘스트 창이 나타납니다. 목표·제한 시간·보상을 확인하고 수락하면 첫 게임이 시작됩니다.
펼쳐진 모포를 두 번, 매트리스를 한 번 직접 접고 매트리스 → 모포 → 베개 순서로 적재합니다.
밝은 귀퉁이를 반대편 원까지 끌어 접습니다. 몸통 드래그로 이동합니다.
휠로 3도씩, Shift와 휠로 1도씩 회전하며 오른쪽 드래그로도 정밀 회전할 수 있습니다.
기본 제한 시간은 60초, 합격선은 80점입니다. 접기 45%, 위치 30%, 각도 25%로 채점합니다.
장비 효과가 있으면 퀘스트 창에 적용된 제한 시간과 보상을 표시합니다. Esc로 일시정지하고 다시 Esc로 재개할 수 있습니다.
통과하면 코인을 받고 홈의 훈련 나가기에서 침상 정리를 다시 플레이할 수 있습니다.
첫 훈련 통과 후에는 조교 점검을 거쳐 탑다운 2D 훈련소 탐색 구역으로 이어집니다.
옆자리 동기와 이야기한 뒤 연병장 조교에게 가면 짧은 제식 이야기가 이어집니다.
'다음 일과로'를 누르면 며칠 뒤 첫 사격 훈련일로 넘어갑니다. 동쪽 사격장 이동로에서 사격 퀘스트를 받습니다.
사격 통과 뒤에는 점수에 따라 조교의 평가가 달라지고, 동기와의 대화가 PX·자유 탐색으로 이어집니다.

사격
45초 동안 팝업 표적 → 이동 표적 → 혼합 표적에 도전합니다.
마우스로 조준하고 왼쪽 클릭으로 발사합니다. R로 8발 탄창을 재장전하고, Esc로 일시정지/재개합니다.
표적을 모두 처리하면 다음 묶음이 바로 나옵니다. 중앙 명중은 PERFECT 보너스, 연속 명중은 콤보를 올립니다.
표적 18개 이상 명중하고 평가 70점 이상이면 통과합니다. 정확도 60%·명중량 20%·중앙 명중 비율 20%로 평가합니다.
기본 명중으로도 합격할 수 있으며 S등급은 중앙을 맞히는 정밀도까지 필요합니다.
결과에서 획득 점수·명중·정확도·최고 콤보를 확인하고 다시 도전할 수 있습니다.
시작 버튼을 누르기 전에는 시간이 흐르거나 소모품을 사용하지 않습니다.
침상 정리와 사격 시작·실패·재도전으로 회복 아이템이 자동 소모되지 않습니다.
예전 14동작 제식 평가는 진행과 훈련 목록에서 제외했습니다. 기존 완료 기록·코인·물품은 유지합니다.

훈련소 탐색과 PX
타이틀의 '훈련소 미리보기'로 먼저 둘러볼 수도 있습니다. 미리보기는 보상이나 본편 위치를 저장하지 않습니다.
WASD/방향키 이동, Shift 달리기, 빈 바닥 클릭 경로 이동, E 대화/시설 이용, M 지도, Esc 메뉴.
I는 아이템창, K는 장비창입니다. 타이틀의 '아이템 · 장비' 버튼으로도 열 수 있습니다.
PX에 이미지가 있는 장비 8종과 소모품 4종이 있습니다. 효과와 가격은 구매 전 상세 창에서 확인합니다.
장비는 부위별 하나씩 착용합니다. 장비창의 앞·왼쪽·오른쪽·뒤와 '걸어보기'로 착용 상태를 확인합니다.
모자·장갑·전투화·손목시계·군장·명찰 외형이 방향과 보행에 맞춰 반영됩니다.
회복 아이템은 아이템창의 '사용하기' 또는 퀵슬롯 1·2에 등록한 뒤 탐색 중 숫자 1·2 / 슬롯 클릭으로 사용합니다.
체력(HP)·지구력(SP)을 회복합니다. 초코파이 HP 30, 믹스커피 SP 35, 에너지바 HP 20 + SP 20, 이온음료 SP 50 회복.
회복이 필요할 때만 1개가 소모됩니다. 이미 가득 찼거나 사용 대기 중이면 수량은 그대로입니다.
아이템의 공유 사용 대기시간은 1.5초입니다. 미리보기와 훈련 중에는 사용하지 않습니다.
Shift로 실제 달리는 동안 SP가 줄고, 쉬면 잠시 뒤 회복됩니다. SP가 떨어지면 걷기로 전환합니다.
현재 전투 장면과 스킬은 아직 제작 전입니다. HP 피해·회복 처리는 이후 전투와 공유할 수 있는 구조이며,
현재 탐색에는 시험용 피해나 체력을 억지로 깎는 기능을 넣지 않았습니다.
미니맵과 장소 이름이 표시되는 전체 지도를 클릭해서 목적지로 이동할 수 있습니다.
생활관에서는 침상 정리 퀘스트/재도전, PX에서는 구매, 훈련 준비실에서는 완료 훈련을 확인합니다.
생활관에서 침상 정리, 사격장 이동로에서 사격을 다시 플레이할 수 있습니다.
탐색에서 시작한 훈련은 완료·실패·중도 포기 후에도 같은 위치로 돌아옵니다. PX를 닫아도 위치가 유지되며 탐색 위치는 자동 저장됩니다.
현재 탐색 지도는 훈련소 분위기를 바탕으로 만든 창작 구역이며 건물 내부·상무대·8사단은 이후 제작합니다.
박환태 중대장·한상철 행보관 대사와 회귀 이후 대사는 원안에 맞춰 붙인 초안입니다.
실제 전역날에 맞춰 세부 대사와 동선을 계속 수정할 수 있습니다.
