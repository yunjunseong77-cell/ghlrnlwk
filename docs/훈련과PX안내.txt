훈련 재도전 / PX / 아이템·장비

홈 화면의 '훈련 나가기'에서 완료한 훈련을 다시 선택합니다.
첫 게임은 침상 정리이며, 회귀 후 스토리의 퀘스트에서 시작합니다.
침상 정리와 사격을 통과하면 홈에 해당 훈련의 완료 기록을 남깁니다. 나머지 훈련은 제작 예정입니다.
사격은 타이틀의 '사격 바로하기'와 훈련 목록의 '바로 도전'에서 미리 플레이할 수 있습니다.
홈에서 먼저 통과해도 본편 사격 퀘스트는 건너뛰지 않습니다. 계정 최초 완료 보상은 한 번만 지급합니다.
예전 제식 평가는 필수 진행과 목록에서 제외하고 기존 기록만 보존합니다.

진행 구조
스토리에서 일러스트 퀘스트 확인 → 수락 후 훈련 시작 → 결과 확정 → 최초 완료 추가 보상 + 등급 보상
→ 재도전 해금 → 홈에서 재도전 → 매 성공마다 등급 보상 → PX 구매 → 보유 물품 장착
실패와 중도 포기는 해금과 코인을 지급하지 않습니다.
재도전에서도 퀘스트 창으로 목표와 보상을 확인합니다. 수락 전에는 제한 시간이 흐르지 않습니다.
침상 정리 기본 조건은 60초 / 80점이며 기본 보상은 첫 성공 150~175 코인, 재도전 50~75 코인입니다.
장비 효과에 따라 퀘스트 창의 제한 시간과 보상 범위가 갱신됩니다. 회복 아이템은 훈련 시작 시 자동 사용하지 않습니다.
퀘스트 취소는 도전을 취소하며 보상이나 완료 기록을 남기지 않습니다.
사격은 45초 동안 팝업·이동·혼합 표적을 처리하며 중앙 명중과 연속 콤보로 높은 점수에 도전합니다.
합격선은 평가 70점과 명중 18개 이상입니다. 평가는 정확도 60%·명중량 20%(35개에서 최대)·중앙 명중 비율 20%입니다.
몸통 명중으로도 기본 합격이 가능하며, S등급은 정밀한 중앙 명중까지 필요합니다.
시작 버튼을 누르기 전에는 세션을 활성화하거나 완료 기록·보상을 변경하지 않습니다.
사격 기본 보상도 첫 성공 150~175 코인, 재도전 50~75 코인이며 장비의 추가 보상 효과를 반영합니다.
통과한 사격의 최고 POINTS와 최고 COMBO를 별도로 저장해 훈련 목록에서도 보여 줍니다.
탑다운 탐색 중에는 생활관에서 침상 정리, 동쪽 사격장 이동로에서 사격 퀘스트를 엽니다.
연병장 조교와 짧은 제식 이야기를 마치면 '며칠 뒤, 첫 사격 훈련일'로 전환합니다.
PX에서는 상점을, 훈련 준비실에서는 재도전 목록을 엽니다.
탐색에서 퀘스트를 취소하거나 훈련을 완료·실패·중도 포기하면 같은 탐색 위치로 돌아옵니다.
탐색 중 연 메뉴와 퀘스트 뒤에서는 이동이 멈춥니다.

현재 수치와 물품은 조정 가능한 초기값입니다.
재화 이름은 data/training_catalog.json의 currency_name에서 한 번에 바꿉니다.
같은 파일에 훈련 목록, 최초 추가 보상, 기본 보상이 있습니다.
PX 물품·가격·효과·이미지 번호는 data/px_items.json에서 관리합니다.
등급: S 95점 이상 / A 85점 이상 / B 70점 이상 / C 그 외 성공 점수
등급 보상: 기본 보상의 150% / 120% / 100% / 60%
성공 여부는 각각의 훈련 게임이 판단합니다. 점수 자체로 성공을 강제하지 않습니다.

PX는 이미지 카드, 장비/소모품 필터, 상세 효과, 가격, 보유 수량을 표시합니다.
아이템창에서 장비를 장착하거나 회복 아이템을 직접 사용하고 퀵슬롯 1·2에 등록합니다.
장비창은 머리·손·발·군장·손목·명찰 6개 슬롯과 현재 효과 합계를 표시합니다.
슬롯을 누르면 그 부위의 보유 장비를 골라 교체할 수 있습니다.
앞·왼쪽·오른쪽·뒤 미리보기와 걸어보기를 통해 방향과 보행 상태의 착용 외형을 확인합니다.
같은 부위는 하나만 장착하며 장비 구매만으로 효과가 발동하지 않습니다.
탐색 중 I는 아이템창, K는 장비창입니다. 같은 키로 닫거나 다른 창으로 바꿀 수 있습니다.

장비 8종
훈련용 장갑 (손, 120): 침구 접기 오차 허용 +15%
군장 어깨 패드 (군장, 180): 탐색 이동 속도 +10%
에이스 명찰 (명찰, 250): 훈련 기본 보상 +10%, 에이스 호칭
경량 전투화 (발, 160): 탐색 이동 속도 +12%
A급 전투모 (머리, 140): 훈련 기본 보상 +5%
군용 손목시계 (손목, 180): 침상 정리 시간 +6초
정밀 작업 장갑 (손, 240): 침구 적재 시 기준각 ±3° 자동 정렬
휴대 수통 (군장, 150): 침상 정리 시간 +5초

소모품 4종 (종류별 최대 99개)
초코파이 (30): HP 30 회복
믹스커피 (15): SP 35 회복
에너지바 (35): HP 20 + SP 20 회복
이온음료 (25): SP 50 회복
아이템창 '사용하기' 또는 탐색 퀵슬롯 1·2(숫자키/클릭)로 명시적으로 사용합니다.
등록·해제·훈련 시작·실패·중도 종료·재도전에서는 수량이 줄지 않습니다.
회복이 필요한 자원에만 적용하고 최대치를 넘기지 않습니다. 효과 적용과 수량 차감은 함께 저장합니다.
회복 불필요·보유 수량 0·공유 1.5초 대기시간·전투불능·훈련 중에는 소모되지 않습니다.
초기 체력(HP)과 지구력(SP)은 100입니다. 탐색 중 실제 달리기에 SP 12/초를 쓰고, 1초 쉬면 SP 8/초씩 회복합니다.
SP 소진 시 걷기로 전환합니다. 미리보기·메뉴·퀘스트 뒤에서는 상태가 변하지 않습니다.
현재 전투 화면과 스킬은 미구현입니다. 피해·회복 API는 이후 전투에 연결할 수 있으며 테스트에서 검증합니다.
현재 탐색에 가짜 피해 버튼이나 회복을 강요하기 위한 피해는 넣지 않았습니다.
장비 효과는 착용 중 유지되며 훈련 시작 시 확정합니다.
사격에서는 에이스 명찰·A급 전투모의 추가 보상 효과가 적용됩니다.
침상 정리 시간·접기·각도 효과는 침상 정리에, 이동 속도 효과는 탐색에만 적용됩니다.
추가 보상은 등급 보상에 적용되며 최초 완료 추가 보상에는 곱하지 않습니다.
접기 보조는 오차 허용 범위와 오차 감점을 완화합니다. 적재 순서와 합격선은 그대로입니다.
모자·두 종류 장갑·전투화·시계·어깨 패드·수통·명찰은 캐릭터 방향과 보행에 맞춘 착용 외형을 사용합니다.
판매용 아이콘과 착용용 렌더링을 분리하고 탐색 캐릭터와 장비창 미리보기가 같은 렌더러를 사용합니다.
프로필은 user://training_profile.cfg에 자동 저장되며 새 이야기 시작 시 유지됩니다.
기존 저장 파일의 코인·장갑·어깨 패드·명찰·훈련 기록은 그대로 불러옵니다.
이전 버전의 준비한 소모품은 수량 차감 없이 퀵슬롯 1로 옮깁니다. 보유 수량·코인·장비·훈련 기록은 유지합니다.
본편의 침상 정리·사격 완료 여부는 progress.cfg의 campaign 상태로 별도 저장합니다. 과거 제식 완료는 사격 완료로 바꾸지 않습니다.
새 이야기를 시작하면 본편 두 훈련을 다시 진행하지만 계정 재도전 기록과 물품은 유지하며 최초 추가 보상은 다시 지급하지 않습니다.

훈련 게임 연결 규약
scripts/training_progress.gd: begin_run(id, "story" 또는 "replay")
성공적인 시작 결과의 token을 보관하고 finish_run(token, 0~100 점수, 성공 여부)로 정산합니다.
실제 플레이를 시작하기 직전 activate_run(token)을 호출해 장비 효과를 확정합니다. 어떤 훈련도 회복 아이템을 자동으로 사용하지 않습니다.
activate_run이 실패하면 타이머를 시작하지 않습니다. 동일 token 재호출은 중복 활성화하지 않습니다.
같은 token은 한 번만 정산할 수 있습니다. cancel_run(token)은 중도 포기 처리입니다.
홈에서 실행할 훈련 씬은 setup_training(store, token) 메서드와 finished 시그널을 제공합니다.
결과 정산 후 finished를 발생시키면 진입한 장소에 따라 탐색 또는 훈련 선택 화면으로 돌아갑니다.
Esc는 훈련 일시정지/재개입니다. 메뉴에서 훈련을 나가면 진행 중인 도전 token을 취소합니다.

검증: tools/verify_training.gd, tools/verify_loadout.gd, tools/verify_camp.gd, tools/verify_shooting.gd, tools/verify_journey.gd,
tools/verify_vitals.gd, tools/verify_rpg_ui.gd, tools/verify_appearance.gd
별도 임시 저장 파일로 해금, 실패, 첫/반복 보상, 중복 정산, 구매, 장착, 재시작 보존을 확인합니다.
플레이어의 실제 프로필에는 테스트 코인이나 테스트 해금 기록을 넣지 않습니다.
